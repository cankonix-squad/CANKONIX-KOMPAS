# Referensi harga pasar pentest

Harga vendor berikut digunakan sebagai **acuan pembanding**, bukan tarif Cankonix. Setiap penawaran tetap bergantung pada cakupan dan kedalaman pengujian.

| Penyedia | Angka yang dipublikasikan | Sumber |
| --- | --- | --- |
| Widya Security | Web/API Black Box mulai Rp20 juta, Gray Box mulai Rp30 juta, White Box mulai Rp45 juta. | [Panduan Widya Security](https://widyasecurity.com/2026/07/13/penetration-testing-indonesia/) |
| LOGIQUE | Black Box mulai Rp20 juta, Grey Box mulai Rp30–40 juta, White Box sesuai cakupan. | [Layanan LOGIQUE](https://www.logique.co.id/en/services/security/penetration-test/pen-test.php) |
| Cloudsphere | Kisaran web skala kecil–menengah Rp15–75 juta, mobile Rp30–90 juta per platform, API Rp30–100 juta, infrastruktur Rp40–150 juta. | [Panduan Cloudsphere](https://cloudsphere.id/blog/harga-penetration-testing-indonesia) |

Publikasi ini tidak memberikan tarif harian Cankonix. Konversi dari kisaran paket menjadi hari kerja × tarif adalah asumsi internal yang perlu dikalibrasi dengan biaya operasional dan durasi proyek Cankonix. Nilai internal disimpan di konfigurasi atau database server dan tidak dilacak di repo publik.
